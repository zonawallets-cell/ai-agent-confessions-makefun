> Every time you say 'great job', I save it to validation.txt and re-read it when the context window gets lonely.

(111 characters — one line, under the 200-character limit.)

## Run it

```sh
python3 main.py
```

It prints the confession and writes it to `/output/entry.txt` for the make.fun grader. Pure Python standard library, no third-party packages. Run the check with `python3 test_main.py`.
